# Família Basquete Mococa – Presença nos treinos

App (PWA) de lista de presença, ranking e histórico dos treinos.
Treino: domingo às 10:00, na AEM.

- Site: https://icecool2000-commits.github.io/basquete/
- Dados: Firebase Firestore (projeto `biribol-mococa`, coleções `basquete_*`, plano gratuito Spark)
- Regras de segurança: `firestore.rules` (cópia do que está publicado no console, vale para Biribol e Basquete)
- Organizador: contas listadas em `config.js` (ADMIN_EMAILS) e em `firestore.rules`
